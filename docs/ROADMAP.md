# Roadmap

This roadmap is focused on making `ai-obs` easier to trust, install, and reuse
across industries.

## Now

- Fix public repository links and package metadata.
- Add privacy, security, roadmap, and industry adoption docs.
- Keep the Docker Compose quickstart working.
- Keep prompt and completion capture disabled by default.

## Next

- Publish the first GitHub release.
- Publish the Python SDK package.
- Publish a versioned collector image to GHCR or Docker Hub.
- Add screenshots or a short demo video of the Grafana dashboards.
- Add issue templates and contribution labels.

## Later

- Add JavaScript and TypeScript SDK support.
- Add built-in redaction hooks and examples.
- Add OpenTelemetry export examples.
- Add Kubernetes and Helm deployment docs.
- Add alerting examples for latency, error rate, cost, and quality drift.
- Add more provider examples for Gemini, Bedrock, Ollama, and local endpoints.

## Release Criteria

A release should include:

- passing CI
- a tagged version
- clear release notes
- quickstart verification
- package or container publishing notes
- known limitations
